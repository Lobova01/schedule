# Расписание занятий факультета

## Описание модели

Проект реализует модель расписания занятий для факультета на Java 21.
Архитектура:

- **Интерфейс `Schedulable`** — общий контракт для всех занятий: день, пара,
  преподаватель, аудитория, группы, длительность.
- **Records** `Classroom`, `Teacher`, `Group`, `Discipline` — неизменяемые
  идентификаторы с валидацией (пустое имя / неположительная вместимость →
  `IllegalArgumentException`).
- **Перечисления:**
    - `PairNumber` — номер пары с полями `startTime` и `endTime`.
    - `WeekParity` — `ODD` / `EVEN` / `ANY` для занятий через неделю.
- **Закрытая (sealed) иерархия `Lesson`** — наследники разрешены только:
    - `Lecture` — лекция для потока (множество групп);
    - `Practice` — практика для одной группы;
    - `Lab` — лабораторная для подгруппы.
- **`ScheduleConflictException`** — собственное исключение при конфликте
  по аудитории, преподавателю или группе.
- **Вспомогательные классы:**
    - `TimeSlot` (record) — день + номер пары, возвращается из поиска окна.
    - `HolidayCalendar` — набор праздничных дат.
    - `WeekParityUtils` — определение чётности недели по ISO.

## Базовый уровень

- Составление расписания на неделю.
- Вывод расписания по группе, преподавателю, аудитории.
- Проверка конфликтов (аудитория / преподаватель / группа) с выбросом
  `ScheduleConflictException`.
- Подсчёт нагрузки преподавателя в часах (через `Duration`).

## Повышенный уровень

- Расписание на диапазон дат с учётом чётности недели и праздников
  (`getScheduleByGroupForRange`).
- Поиск ближайшего свободного окна заданной длительности
  (`findNearestFreeSlot`).

## Технологии

- Java 21: `record`, `sealed`, pattern matching в `switch`, `var`.
- Maven.
- JUnit 5.
